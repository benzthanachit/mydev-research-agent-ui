# 🐾 Meow-nuscript Foundry (โรงหล่อต้นฉบับแมวเหมียว)

**Meow-nuscript Foundry** คือเว็บแอปพลิเคชันระบบ **Multi-Agent AI** ในสไตล์ย้อนยุค **90s Retro 8-bit RPG** (ธีมออฟฟิศแมวสุดน่ารัก 🐱) ที่พัฒนาขึ้นโดยเฉพาะเพื่อช่วยเหลือและอำนวยความสะดวกแก่นักวิจัยในการเขียนและตรวจทานบทความวิจัยทางวิชาการ (Academic Manuscripts) ตามมาตรฐานของวารสารวิชาการระดับ **Scopus Q3 และ Q4** 

ระบบนี้ดำเนินงานด้วยการแบ่งขั้นตอนเป็นรายบทอย่างเคร่งครัด (**Chapter-by-Chapter Workflow**) พร้อมระบบอนุมัติโดยมนุษย์ (**Human-in-the-loop**) เพื่อประสิทธิภาพในการควบคุมเนื้อหาสูงสุด

---

## 🎮 บทบาทของตัวละครแมวออฟฟิศ (4 Cat Agents & Siamese Mascot)

1.  **แมววิเชียรมาศ (Siamese Cat - UI Mascot):** ทำหน้าที่เป็นพนักงานนำส่งข้อมูลหลัก เดินผ่านหน้าจอพร้อมอัญเชิญป๊อปอัปแจ้งเตือนเมื่อเกิดสถานะสำคัญในระบบ
2.  **Project Meow-nager (Agent 1 - ผู้จัดการสุดสมาร์ท 👓):** ทำหน้าที่สรุปความเห็นของผู้ประเมินเป็นหัวข้อกระชับ คอยประสานงาน และรอรับคำแนะนำเพิ่มเติมจากนักวิจัยก่อนดำเนินการต่อ
3.  **The Scribe Cat (Agent 2 - นักเขียนมือทอง ✍️):** ทำหน้าที่ดึงข้อมูลเชิงเทคนิค อัลกอริทึม หรือสมการที่กำหนด มาร่างเนื้อหารายละเอียดวิทยานิพนธ์อย่างเป็นทางการและถูกต้องตามหลักวิชาการ
4.  **Grumpy Reviewer (Agent 3 - ผู้ประเมินสุดเฮี้ยบ 🎓):** ทำหน้าที่ตรวจประเมินตามมาตรฐาน Scopus Q3/Q4 โดยเน้นที่ระเบียบวิธีวิจัยที่สมบูรณ์ ความสมเหตุสมผล และคอยห้ามปรามไม่ให้เคลมผลการวิจัยเกินจริง (No Overclaiming) พร้อมให้ผลตัดสินอย่างเด็ดขาดเป็น `[FAIL]` หรือ `[PASS]`
5.  **The Librarian Cat (Agent 4 - บรรณารักษ์ผู้ละเอียดลออ 📚):** ทำหน้าที่ตรวจทานรูปแบบการเขียนอ้างอิงและบรรณานุกรม (Citation QA) ตามระบบมาตรฐานวิชาการ เช่น APA หรือ IEEE

## 🛠️ วิธีการตั้งค่าก่อนรัน (Pre-run Setup)

แอปพลิเคชันนี้ออกแบบมาให้พร้อมใช้ทันทีหลังจากรัน (Out-of-the-box) โดยมีระบบ **Mock Mode (ออฟไลน์)** คุณภาพสูงจำลองการตอบกลับทางวิชาการอย่างสมจริง หากคุณต้องการเชื่อมโยงเข้ากับระบบจริง ให้ดำเนินการตั้งค่าตามขั้นตอนดังนี้:

### 1. การเชื่อมต่อ Gemini API (สมองกลหลัก)
คุณสามารถเชื่อมโยงระบบเข้ากับ **Gemini 1.5 Flash API** ได้ 2 ช่องทาง:
*   **ทางหน้าเว็บ UI (สะดวกที่สุด):** เข้าไปที่แท็บ **Cognitive Settings [4]** บนหน้าจอ แล้วป้อน **Gemini API Key** ของคุณ ระบบจะบันทึกลงในหน่วยความจำเครื่อง (Browser `localStorage`) ทันทีโดยไม่ต้องเปิดเผยรหัสผ่าน
*   **ทางไฟล์คอนฟิก (.env):** สร้างไฟล์ `.env.local` ไว้ที่โฟลเดอร์หลักของโปรเจกต์ (Root Directory) จากนั้นเพิ่มบรรทัดนี้:
    ```env
    GEMINI_API_KEY=your_actual_gemini_api_key_here
    ```

### 2. การตั้งค่า Obsidian Working Memory (ความจำระยะสั้น)
ระบบจะทำการบันทึก **"Micro-Facts"** และ **"Decision Logs"** เพื่อใช้เป็นบริบทในการเขียนบทถัดไปโดยไม่ทำให้ Context Window ของบอทล้น
*   **หากมี Obsidian ในเครื่อง:** เข้าไปที่แท็บ **Cognitive Settings [4]** และใส่ที่อยู่โฟลเดอร์จริงของ Obsidian Vault ลงในช่อง (เช่น `/Users/username/Documents/MyResearchVault`)
*   **หากไม่มี Obsidian:** ปล่อยว่างไว้ ระบบจะจำลองโฟลเดอร์เก็บข้อมูลชื่อ `obsidian-vault` ขึ้นมาที่โฟลเดอร์หลักของโปรเจกต์โดยอัตโนมัติ ซึ่งคุณสามารถเข้าตรวจดูไฟล์ `.md` ได้โดยตรงในโปรเจกต์นี้!

### 3. การตั้งค่า NotebookLM Cold Storage (คลังเอกสารแช่แข็ง)
เมื่อแต่ละบทผ่านการอนุมัติและกดล็อกบท ระบบจะส่งข้อมูลไปจัดเก็บ
*   **เชื่อมระบบจริง:** ป้อนที่อยู่ **Webhook URL** ของระบบ NotebookLM ในช่อง Settings
*   **จำลองระบบ:** ปล่อยว่างไว้ ระบบจะทำการจัดเก็บไฟล์บทความที่เซฟและลงลายลักษณ์อักษรแบบถาวรไว้ที่โฟลเดอร์ `notebooklm-cold-storage` ภายในโปรเจกต์โดยอัตโนมัติ

## 🚀 วิธีการรันแอปพลิเคชัน (How to Run)

หลังจากทำตามขั้นตอนการตั้งค่าเรียบร้อยแล้ว ให้เปิด Terminal ในโฟลเดอร์หลักของโปรเจกต์ แล้วทำตามขั้นตอนดังนี้:

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รัน Developer Server (เซิร์ฟเวอร์ทดสอบ)
```bash
npm run dev
```

หลังจากนั้น เปิดเว็บเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000) เพื่อเริ่มต้นงานเขียนร่วมกับแก๊งออฟฟิศแมวเหมียว!

## 🔄 ขั้นตอนการดำเนินงานเขียน (State Machine Workflow)

1.  **เตรียมการและป้อนเป้าหมาย (Stage Selection):** ป้อนหัวข้อโครงร่าง ระเบียบวิธี และการทำงานของสมการในแท็บ **Workbench [1]**
2.  **ร่างข้อมูล (Drafting State):** กดปุ่ม **"RUN SCRIBE CAT DRAFT"** บรรดาแมวนักเขียนจะเริ่มดึงข้อมูลจากความจำมาเขียน และคุณสามารถกดดูฉบับร่างได้ทันทีที่แท็บ **Manuscript Draft [2]** (สามารถแก้ไขข้อความได้โดยตรงในฐานะมนุษย์ผู้ตรวจสอบ)
3.  **ประเมินผลสุดโหด (Review State):** กดส่งให้ตรวจประเมิน หากเกิด `[FAIL]` จาก Grumpy Reviewer ป๊อปอัปออฟฟิศจะติดกรอบสีแดงพร้อมรายการจุดบกพร่องวิชาการที่ต้องแก้ ให้ปรับค่าแล้วกดเขียนใหม่ หากตรวจผ่าน (`[PASS]`) จะเปิดทางสู่ระบบบรรณารักษ์
4.  **ตรวจสอบการอ้างอิง (Citation Check):** รัน Librarian Cat เพื่อเช็กรูปแบบฟอร์แมตอ้างอิง ข้อมูลจะปรากฏขึ้นบนม้วนกระดาษโบราณจำลอง
5.  **ล็อกล็อกความสำเร็จ (Save State):** เมื่อทุกขั้นตอนเรียบร้อย กดปุ่ม **🔒 LOCK & SAVE** เพื่อเก็บข้อมูลลงคลังความจำ Obsidian และแช่แข็งผลลัพธ์ลง NotebookLM ก่อนเริ่มบทถัดไป!

## 💻 เทคโนโลยีที่ใช้หลัก (Core Stack)
*   **Frontend:** Next.js 16 (React 19), Tailwind CSS v4 
*   **Styling (ธีมย้อนยุค):** Google Fonts (Press Start 2P, VT323) ร่วมกับการจัดโครงสร้าง HTML `<img>` tags ที่ประมวลผลพิกเซลพิกเซลดึงเอาความคมชัดดั้งเดิมของภาพ RPG
*   **AI Engine:** Gemini API ผ่านแพ็กเกจอย่างเป็นทางการ `@google/generative-ai` พร้อมระบบควบคุม Persona อัตโนมัติ
